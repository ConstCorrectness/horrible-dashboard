# dash — the REPL handle

`dash` is seeded into every in-app Python REPL session and scripts the running dashboard — panes, layout, I/O, settings, git — and every module can add a `dash.<name>` facade (`dash.lens` reads llama.cpp traces as numpy). `dash.help()` prints the same list at the prompt. It is a global, not an importable module: there is no `import dash`. See [the Python SDK](../architecture/python-sdk.mdx).

Also browsable, with search, in the **Python reference** pane (`/pydoc`) under *Dashboard SDKs*.

## `dash`

### `call`

````text
call(name: str, **args: Any) -> Any
````

````text
Relay an arbitrary tool by name — covers every widget `agentTool` and
agent-exposed command, so new capabilities are reachable without an SDK
change.
````

### `context`

````text
context(instance_id: str) -> Any
````

````text
Read an active pane instance's current state/selection snapshot (instanceId from
`panes.open_list()`).
````

### `help`

````text

````

````text
Print the whole `dash` surface (facades, methods, and one-line docs).
````

### `search`

````text

````

