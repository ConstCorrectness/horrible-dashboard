# Minimal

A personal blog that gets out of the way. One column, the post list is the home page.

Voice: first person, plain words, short paragraphs. Lead with the point in the first
two sentences; the description doubles as the post list's summary line, so write it as
one sentence a reader would click on.

Layout notes for writers:

- The title comes from the frontmatter. Do not repeat it as a `# Heading`.
- Sections are `##`. Use `###` sparingly; this theme does not number headings.
- Figures go full column width. Prefer one strong figure over several small ones.
- Tags appear under the title and get their own index pages; use two or three.
