Title: 🚀 Feat: High-performance Linux Electron desktop shell, packaging, and benchmark suite

Description:
### 🎯 What & Why
- **Problem**: On Linux, running Tauri resulted in severe rendering lag and eventual Out-of-Memory (OOM) crashes due to WebKitGTK / Wayland DMA-BUF buffer leakage during continuous WebGL canvas rendering (`Avatar3D.tsx`).
- **Solution**: Built a dedicated, high-performance Electron desktop shell in `apps/desktop-electron` with hardware acceleration flags (`--enable-zero-copy`, `--ignore-gpu-blocklist`, `--no-sandbox`), while preserving Tauri in `apps/desktop` for Windows/macOS where WebView2 operates smoothly.
- **Packaging & Updates**: Configured `electron-builder` for multi-platform distribution (`.AppImage`, `.deb`, NSIS `.exe`, `.zip`) and integrated `electron-updater` directly into the frontend update notification system.
- **Performance Benchmarks**: Developed a standalone cross-platform benchmark suite (`scripts/benchmark-desktop.mjs`) to measure boot latency, physical memory footprint (RSS across process tree), memory growth slope (MB/min), and CPU utilization across Electron and Tauri.

---

### 📦 Key Changes
1. **Desktop Electron Shell (`apps/desktop-electron`)**:
   - `src/main.ts`: Chromium flags, single instance lock, window lifecycle, and static asset fallback.
   - `src/preload.ts` & `scripts/wrap-preload.cjs`: Secure `contextBridge` exposing `window.horriblePlatform` with CommonJS module polyfill.
   - `src/backend.ts`: FastAPI backend supervisor with port-probe discovery and process group shutdown.
   - `src/browserView.ts`: Embedded child webviews via `WebContentsView` with native Chrome DevTools Protocol (`webContents.debugger`).
   - `src/updater.ts`: Auto-updater integrating `electron-updater` with GitHub Releases.
   - `electron-builder.json`: Bundles `apps/web/dist` and relocatable Python `backend-runtime`.
2. **Frontend & Core Integration**:
   - `apps/web/src/main.tsx`: Runtime detection of `window.horriblePlatform` and desktop capability injection.
   - `apps/web/src/electronBackend.ts`, `electronShortcuts.ts`, `electronWindow.ts`: Desktop seams for port discovery, global accelerators, and window controls.
   - `packages/core/src/external.ts`: Desktop URL opening and OS directory reveal support for Electron.
   - `packages/core/src/modules/updates/api.ts`: Connected `checkForUpdate` and `installUpdate` to Electron updater bridge.
   - `packages/ui/src/layout/frame.css`: Added `-webkit-app-region: drag/no-drag` for frameless window movement.
3. **Tooling & Benchmarking**:
   - `scripts/dev-desktop.mjs`: Auto-selects Electron on Linux and Tauri on Windows/macOS, with explicit `--shell <electron|tauri>` override.
   - `scripts/benchmark-desktop.mjs`: Cross-platform benchmark suite tracking startup to interactive, memory leaks, and CPU load.
